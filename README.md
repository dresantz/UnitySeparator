# UnitySeparator
Um código para manipular a GUI do Unity na Hierarchy, permitindo personalizar um Game Object vazio para transformá-lo em um separador, ajudando na organização do projeto.

Apenas arraste o código Separador.cs para um Game Object vazio que você queira transformar em um separador, para que ele fique estilizado:
![Texto Alternativo](https://raw.githubusercontent.com/dresantz/UnitySeparator/refs/heads/main/Tutorial3.png)

No Inspector, será possível configurar cor de fundo, raio da borda e colocar um ícone no objeto.
![Texto Alternativo](https://raw.githubusercontent.com/dresantz/UnitySeparator/refs/heads/main/Tutorial4.png)


Para evitar qualquer acidente, desative o objeto no Inspector e ative a mãozinha do lado do nome do Objeto na Hierarchy.
